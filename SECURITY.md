# Security policy

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting flow from the repository's
**Security** tab. Include the affected URL or file, a concise reproduction,
the impact, and any suggested mitigation. Remove credentials and private data
from the report unless they are essential to reproduce the issue.

If private vulnerability reporting is unavailable, contact the repository
owner through the GitHub profile and ask for a private reporting channel.
